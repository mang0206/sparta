# Docker 컨테이너 로그 확인

`docker logs` 명령어는 실행 중이거나 중지된 컨테이너의 표준 출력(stdout)과 표준 에러(stderr)를 확인하는 데 사용됩니다. 애플리케이션의 동작을 모니터링하고 문제를 디버깅하는 데 필수적인 도구입니다.

## 1. 실행 중인 컨테이너의 전체 로그 확인

컨테이너의 이름이나 ID를 `docker logs` 명령어 뒤에 붙여 해당 컨테이너가 생성된 이후의 모든 로그를 출력합니다.

```bash
# 'spring-app' 컨테이너의 모든 로그 보기
docker logs spring-app
```

## 2. 실시간 로그 확인 (Follow)

`-f` 또는 `--follow` 옵션을 사용하면, 로그 파일의 끝부분을 계속해서 스트리밍 형태로 보여줍니다. 실시간으로 발생하는 이벤트를 모니터링할 때 유용합니다.

```bash
# 'spring-app' 컨테이너의 로그를 실시간으로 확인
# (Ctrl+C를 눌러 종료)
docker logs -f spring-app
```

## 3. 특정 개수의 최근 로그만 출력

`--tail` 옵션을 사용하면 로그의 마지막 N줄만 출력할 수 있습니다. 시스템의 최근 상태를 빠르게 확인할 때 유용합니다.

```bash
# 'spring-app' 컨테이너의 마지막 10줄 로그만 보기
docker logs --tail 10 spring-app
```

## 4. 타임스탬프와 함께 로그 보기

`-t` 또는 `--timestamps` 옵션을 추가하면 각 로그 라인 앞에 타임스탬프가 표시되어, 로그가 기록된 시간을 정확히 알 수 있습니다.

```bash
docker logs -t spring-app
```

## 5. 여러 옵션 조합하기

옵션들은 조합하여 사용할 수 있습니다. 예를 들어, 최근 50줄의 로그를 보여주고, 그 이후부터 실시간으로 로그를 추적하려면 다음과 같이 실행합니다.

```bash
docker logs --tail 50 -f spring-app
```
